# 宽基定投温度监控

> 把「现在贵不贵、该不该多投」变成一个 0–100 的温度，并给出本期的定投倍率。
> 本地运行，无账号、无第三方 Python 依赖，双击 `启动.bat` 即用。

---

## 一、这是什么

一个跑在本机的宽基指数监控面板，覆盖 10 只标的：

| 市场 | 标的 |
|---|---|
| A股 | 沪深300、中证500、中证1000、创业板50、科创50、中证A500、上证50 |
| 美股 | 标普500、纳斯达克100 |
| 港股 | 恒生科技 |

每只标的回答四个问题：

1. **现在贵不贵** —— PE/PB 历史分位、价格历史分位；
2. **处在什么位置** —— 距历史高点回撤、距 200 日线偏离、RSI、60 日动量；
3. **本期该投多少** —— 由温度分映射成 0.3× / 0.5× / 1.0× / 1.5× / 2.0× 五档倍率；
4. **这套规则历史上管不管用** —— 全历史定投回测，按信号倍率 vs 等额定投逐年对比。

## 二、方法论（这平台是基于什么做的）

### 2.1 位置分（纯价格，0–100，越高越接近低位）

| 因子 | 计算方式 | 权重 | 得高分意味着 |
|---|---|---|---|
| 价格分位 | 当前收盘价在近 N 年（默认 5 年，可切 3/10/年全史）交易日中的分位 `pct` | 30% | 比历史上多数时间便宜 |
| 距历史高点 | `close / max(close 至今) − 1`，跌幅 50% 记满 100 分 | 25% | 回撤越深越接近底部区域 |
| 200 日线偏离 | `50 − 偏离率 × 250`，偏离 −20% → 100 分，+20% → 0 分 | 20% | 显著跌破年线 |
| RSI(14) | `(70 − RSI) / 40 × 100`，RSI 30 → 100，70 → 0 | 15% | 短期超卖 |
| 60 日动量 | `50 − 60日涨跌幅 × 150` | 10% | 中期跌得多 |

`位置分 = Σ(因子分 × 权重)`，各因子统一裁剪到 [0,100]。

### 2.2 估值分（0–100，越高越便宜）

```
估值分 = 100 − (PE 历史分位 + PB 历史分位) / 2 × 100
```

PE 与 PB 分位取自蛋卷基金的指数估值接口（见 2.4）。**只取两者均值，是因为二者经常背离**：
盈利下滑会把 PE 推高而 PB 不动（沪深300 就是这种情况），只看 PE 会把「盈利差」误读成「贵」。

无 PE/PB 数据的标的（标普500、中证A500、创业板50）自动降级为纯位置分，并在卡片上标 `无数据`。

### 2.3 合成与倍率

```
温度分 = 位置分 × (1 − w) + 估值分 × w        # w = 估值权重，默认 0.30，界面可调 0–60%
温度   = 100 − 温度分
```

| 温度 | 含义 | 倍率 |
|---|---|---|
| < 25 | 极冷 · 历史低位 | 2.0× 加码 |
| 25–40 | 偏冷 | 1.5× 增额 |
| 40–65 | 中性 | 1.0× 常规 |
| 65–80 | 偏热 | 0.5× 减额 |
| ≥ 80 | 过热 · 历史高位 | 0.3× 缩量 |

### 2.4 回测口径（重要）

- **频率**：每 21 个交易日（约一个月）投一次，可切每周(5)/每两周(10)；
- **金额**：`基准金额 × 当期倍率`，与「每期固定等额」做对照；
- **起点**：第 250 个交易日（保证 200 日线可用），到最新交易日；
- **无未来函数**：t 时刻的分数只用 t 及之前的数据计算；
- **年化**：用 XIRR（资金加权内部收益率，二分法求解），不是简单的「总收益 ÷ 年数」；
- **可比口径是年化，不是总收益或市值**：信号策略的投入总额与等额策略不同（平均倍率不是 1），
  所以「期末市值」和「总收益率」不能直接横比，界面上以年化为主指标，并在副标题注明；
- **最大浮亏**：定投期间市值相对累计投入的最大回撤幅度；
- **口径差异**：历史 PE/PB 序列拿不到，**回测中的信号只含位置分（等价于估值权重 = 0）**。
  界面上的实时倍率含估值，二者不完全等价 —— 这一点在文档和界面上都如实标注，不用回测结果冒充含估值的策略。

## 三、数据从哪来

| 用途 | 来源 | 接口 | 缓存 | 已知限制 |
|---|---|---|---|---|
| 日线行情（含当日盘中） | 东方财富 | `push2his.eastmoney.com/api/qt/stock/kline/get` | 60 秒 | 非官方公开 API，字段可能变动；港股/美股收盘时间不同步 |
| 纳指100 长历史（1996 起） | 纳斯达克官网 | `api.nasdaq.com/api/quote/NDX/historical` | 6 小时 | 只有 OHLC，**无成交量**；不含当日盘中，需与东财拼接 |
| PE / PB 及历史分位 | 蛋卷基金 | `danjuanfunds.com/djapi/index_eva/detail/{code}` | 30 分钟 | 分位窗口未公开（官方口径约 10 年）；仅覆盖部分指数 |

均为 HTTP GET + JSON，无需 token。行情走前复权（`fqt=1`），指数无分红影响。

**纳指100 为什么要两个源拼接**：东财的 `100.NDX100` 只回溯到 2019-04（1909 根），算 10 年分位都不够；
`100.NDX` 是纳斯达克**综合指数**（1991 起 8872 根），不是纳指100，混用会算错。
纳斯达克官网能拿到 1996-06-06 起的 7834 根，但滞后 1–2 个交易日且无成交量。
做法：官网历史打底 + 东财覆盖 2019-04 之后的近端（含盘中），拼接点前后收盘价连续（2019-04-05 收 7578.84 → 2019-04-08 收 7599.74）。
两源在 1908 个重叠交易日中，仅 1 天收盘价偏差超过 0.2%（2021-05-14，+0.60%，属单源错价）。

**各标的实际数据跨度**（决定了「全部」区间分位与全历史回测的可用长度）：

| 标的 | 起 | 交易日 | 说明 |
|---|---|---|---|
| 标普500 | 1990-01 | 9331 | 东财 |
| 纳斯达克100 | 1996-06 | 7835 | 官网 + 东财拼接（本次升级，原为 2019-04） |
| 上证50 | 2004-01 | 5549 | |
| 沪深300 / 中证500 / 中证1000 / 中证A500 | 2005-01 | 5306 | A500 为回溯数据 |
| 创业板50 | 2014-06 | 3014 | 指数发布日，无法再往前 |
| 恒生科技 | 2014-12 | 2918 | 指数基日，无法再往前 |
| 科创50 | 2019-12 | 1661 | 2020-07 发布，2019-12 为基日回溯，**无法再延长** |

## 四、快速开始

```
双击  启动.bat
```

会做三件事：起一个本地 HTTP 服务（127.0.0.1，端口 8765 起，被占用则顺延）、自动打开浏览器、关闭命令行窗口即停止服务。

命令行等价：

```bash
python 服务端.py
```

**环境**：Python 3.9+，只用标准库（`http.server` / `urllib` / `json` / `concurrent.futures`），
不需要 `pip install`。前端 ECharts 已离线内置于 `web/vendor/`，断网也能开页面看缓存数据。

## 五、界面与参数

- **卡片**：按温度升序排列（最该加码的在最前），含温度条、倍率、本期建议金额、PE 分位、价格分位、距高点、距 200 日线、近 60 日走势；
- **详情**：K 线（含 MA60 / MA200 / 成交额、可缩放），K 线上方一行给出**该区间的涨幅、年化、区间最高/最低、起止日期与交易日数**（切 1月/3月/6月/1年/3年/5年/10年/全部 时同步重算）；定投回测曲线；因子明细表（每项读数、得分、权重）；
  - 均线在全历史上滚动计算后再切到所选区间，所以 1 个月视图里的 MA200 也是真实值，不是空线；
  - 区间含「纳斯达克官网历史」（无成交量）时自动隐藏成交额副图并提示，不把缺失画成 0；
- **参数**（右上角「参数」，自动存 localStorage）：
  - 分位窗口：3 年 / 5 年 / 10 年 / 全历史
  - 估值权重：0–60%（0% 即纯位置策略，与回测口径一致）
  - 每期基准金额
  - 定投频率：每周 / 每两周 / 每月
  - 自动刷新：关闭 / 60 秒 / 5 分钟

## 六、口径与限制（请先读这一段）

1. **分位不是概率**。价格处在 5 年 30% 分位，只说明「过去 5 年有 70% 的交易日比现在贵」，不预测未来。
2. **估值分位窗口不同源**。鸡蛋卷的 PE/PB 分位与本地算的价格分位窗口并不一致（前者窗口未公开），所以二者合成时只能算近似。
3. **A500 的历史是回溯数据**。中证A500 2024 年 9 月才发布，2024 年之前是编制方回溯，分位仅供参考。
4. **部分指数历史天生短**。科创50 只有 6.9 年（2020-07 才发布），创业板50、恒生科技各约 12 年，都是指数发布/基日所限，**外部没有任何合法长历史可补**——这类标的切换「全历史」窗口时分位会偏窄，建议用 3 年窗口并降低对结论的置信度。纳指100 已从 7 年补到 30 年（1996 起）。
5. **跨境标的**另有汇率、QDII 溢价、额度限制，页面上的价格分位不含这些摩擦成本。
6. **信号是纪律工具，不是择时圣杯**。月投 1000 元、2006 年至今的实测：

| 标的 | 区间 | 按信号年化 | 等额年化 | 最大浮亏（信号/等额） |
|---|---|---|---|---|
| 沪深300 | 2006-01 ~ 2026-10 | 2.75% | 2.54% | −23.8% / −15.7% |
| 创业板50 | 2015-06 ~ 2026-10 | 5.47% | 4.03% | −39.0% / −42.2% |
| 恒生科技 | 2016-01 ~ 2026-11 | −0.89% | −1.95% | −28.1% / −33.6% |
| 标普500 | 1990-12 ~ 2026-10 | 9.19% | 8.89% | −6.8% / −1.9% |
| 纳斯达克100 | 1997-05 ~ 2026-11 | **14.01%** | 13.43% | −39.7% / −43.4% |

   纳指100 是补到 30 年历史后才能算出来的一行 —— 时间跨度跨过了 2000 年互联网泡沫与 2008 年，
   信号比等额高 0.58pp、最大浮亏浅 3.7pp。**跨度越长，这一栏越可信；只有 7 年数据时不要下结论。**

   在震荡与下跌市里信号降低亏损或抬高年化，代价是最大浮亏更深（因为低位加倍投入）；
   长期单边上涨市场里优势收窄到 0.3 个百分点。**这些结果原样展示，不做粉饰。**
