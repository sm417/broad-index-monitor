# 宽基定投温度监控

> 把「现在贵不贵、该不该多投」变成一个 0–100 的温度，并给出本期的定投倍率。
> 本地运行，无账号、无第三方 Python 依赖，双击 `启动.bat` 即用。

**一分钟版本**：先看 [简介.md](简介.md)。本文是完整的技术文档 —— 因子公式、数据源、回测口径与已知限制。

---

## 一、这是什么

一个跑在本机的宽基指数定投监控面板，覆盖 11 只标的：

| 市场 | 标的 |
|---|---|
| A股 | 沪深300、中证500、中证1000、创业板50、科创50、中证A500、上证50 |
| 美股 | 标普500、纳斯达克100 |
| 港股 | 恒生科技 |
| 商品 | 黄金（上海金 AU9999） |

每只标的回答四个问题：

1. **现在贵不贵** —— PE/PB 历史分位、价格历史分位（黄金无 PE/PB，该因子自动剔除）；
2. **处在什么位置** —— 距历史高点回撤、距 200 日线偏离、RSI、60 日动量；
3. **本期该投多少** —— 由温度分映射成 0.3× / 0.5× / 1.0× / 1.5× / 2.0× 五档倍率；
4. **这套规则历史上管不管用** —— 全历史定投回测，按信号倍率 vs 等额定投逐年对比。

> 黄金放在这里是因为它和股票指数的相关性低，是「另一个独立的加码对象」，
> 不是因为它也是宽基。它的判断口径与股指不完全相同，见第六节末的附表说明。

## 二、方法论（这平台是基于什么做的）

> 当前模型 **v2**（2026-11 改版）。v1 保留在「参数 → 评分模型」里，可随时切换对照，差异见 2.5。

### 2.1 先讲一个被实测证伪的做法

v1 用「当前价在近 N 年内的分位」判断贵贱。这对牛熊循环的 A 股大致可用，但对**长期上行的指数
有系统性偏差**：价格水平本身带漂移，指数涨了十年，几乎每天都处在「历史高位」。

用固定预算口径回测（月投 1000，每期预算 2000，闲置现金入账，各标的全历史）：

| 标的 | v1 平均倍率 | v1 同预算财富 vs 等额 |
|---|---|---|
| 标普500 | 0.60× | **−25.0%** |
| 纳斯达克100 | 0.90× | +4.5% |
| 沪深300 | 1.11× | +2.6% |

v1 让标普 500 少投了三十年，最终财富反而比等额定投低四分之一——它把「创新高」当成了「贵」，
而标普 500 在 1990–2026 有七成时间处在 5 年区间的上半部。

### 2.2 v2 的五个因子（全部是「自身历史分位」）

不跨标的比较，也不用绝对百分比阈值——同一个 −10% 回撤，对纳指是难得的机会，对恒生科技是常态。

| 因子 | 计算方式 | 权重 | 得高分意味着 |
|---|---|---|---|
| 趋势位置 | `close / MA200 − 1`，该偏离在本标的全历史中的分位 | 28% | 低于自身趋势线 |
| 回撤分位 | 当前回撤在本标的历史回撤分布中的分位 | 18% | 这次回撤对它自己算深的 |
| 短期超卖 | 20 日高点回撤分位 50% ＋ `(70 − RSI14) / 40 × 100` 50% | 18% | 短线跌透了 |
| 距长期趋势 | 价格对「10 年对数价格线性趋势」的偏离，取历史分位 | 18% | 低于长期趋势线 |
| 估值分位 | `100 − (PE分位 + PB分位) / 2 × 100` | 18% | PE/PB 在历史低位 |

分工是关键：**前三项衡量「便宜」，后两项衡量「贵」**。创新高只会轻微影响第一项，
不再像 v1 那样一票把温度推到 65 以上；而真正该警惕的贵——价格远离十年趋势线、
或 PE/PB 处在历史极高分位——由后两项负责，2000 年纳指、2007 与 2015 年 A 股都在这两项上触顶。

PE 与 PB 取均值而非单看一个：盈利下滑会把 PE 推高而 PB 不动（沪深300 常见），只看 PE 会把
「盈利差」误读成「贵」；反之创业板指也曾出现 PE 分位 7% 而价格在 5 年 60% 分位的背离。

无 PE/PB 数据的标的（标普500、中证A500、创业板50、黄金）按剩余权重归一，不惩罚也不加分；
黄金是天然没有估值因子，处理方式见第六节末的附表说明。

### 2.3 合成与倍率

```
温度分 = Σ(因子分 × 权重) / Σ权重        # 无 PE/PB 时按剩余权重归一
温度   = 100 − 温度分
```

| 温度 | 含义 | 倍率 |
|---|---|---|
| < 25 | 极冷 · 历史低位 | 2.0× 加码 |
| 25–40 | 偏冷 | 1.5× 增额 |
| 40–65 | 中性 | 1.0× 常规 |
| 65–80 | 偏热 | 0.5× 减额 |
| ≥ 80 | 过热 · 历史高位 | 0.3× 缩量 |

模型能不能「认得」泡沫和底部，比回测收益更能说明问题（下表由当前代码直接算出）：

| 时点 | 温度 | 建议 |
|---|---|---|
| 沪深300 2007-10-16（6124 点） | 80.5 | 0.3× 缩量 |
| 沪深300 2008-10-28（1664 点） | 0.8 | 2.0× 加码 |
| 沪深300 2015-06-12（5178 点） | 89.2 | 0.3× 缩量 |
| 沪深300 2021-02-18（茅指数顶） | 87.6 | 0.3× 缩量 |
| 沪深300 2024-02-02（雪球敲入低点） | 20.3 | 2.0× 加码 |
| 标普500 2000-03-24（科网顶） | 83.0 | 0.3× 缩量 |
| 标普500 2002-10-09（熊市底） | 1.0 | 2.0× 加码 |

### 2.5 回测口径：同预算，含闲置现金

- **频率**：每 21 个交易日（约一个月），可切每周 / 每两周；
- **预算**：每期固定 `基准 × 2`；按倍率投出 `基准 × 倍率`，没投出的计入现金（不计息）；
- **期末财富** ＝ 持仓市值 ＋ 现金，与「每期都按基准等额投出」的策略比较；
- **无未来函数**：t 时刻的分数只用 t 及之前的数据计算；
- **年化**：XIRR，现金流按「每期总预算」计，因此包含闲置现金的拖累；
- **为什么不比「每投 1 元的收益」**：那个指标会奖励「牛市少投」——少投的钱不进入分母，
  收益率自然变高，但总财富并没有变多。v1 在标普 500 上的「每元收益」比等额高 3.6%，
  换成同预算口径却是 **−25.0%**。这是本次改版最关键的一处口径修正。
- **已知偏差**：回测中的信号会用到该标的「当前的 PE/PB 分位」快照（历史估值序列拿不到），
  所以含估值的回测不是逐日历史估值，只能算近似。

## 三、数据从哪来

| 用途 | 来源 | 接口 | 缓存 | 已知限制 |
|---|---|---|---|---|
| 日线行情（含当日盘中） | 东方财富 | `push2his.eastmoney.com/api/qt/stock/kline/get` | 60 秒 | 非官方公开 API，字段可能变动；港股/美股收盘时间不同步 |
| 纳指100 长历史（1996 起） | 纳斯达克官网 | `api.nasdaq.com/api/quote/NDX/historical` | 6 小时 | 只有 OHLC，**无成交量**；不含当日盘中，需与东财拼接 |
| PE / PB 及历史分位 | 蛋卷基金 | `danjuanfunds.com/djapi/index_eva/detail/{code}` | 30 分钟 | 分位窗口未公开（官方口径约 10 年）；仅覆盖部分指数 |

均为 HTTP GET + JSON，无需 token。行情走前复权（`fqt=1`），指数无分红影响。

**纳指100 为什么要两个源拼接**：东财的 `100.NDX100` 只回溯到 2019-04（1909 根），算 10 年分位都不够；
`100.NDX` 是纳斯达克**综合指数**（1991 起 8872 根），不是纳指100，混用会算错。
纳斯达克官网能拿到 1996-06-06 起的 7834 根，但滞后 1–2 个交易日且无成交量。
做法：官网历史打底 + 东财覆盖 2019-04 之后的近端（含盘中），拼接点前后收盘价连续（2019-04-05 收 7578.84 → 2019-04-08 收 7599.74）。
两源在 1908 个重叠交易日中，仅 1 天收盘价偏差超过 0.2%（2021-05-14，+0.60%，属单源错价）。

**各标的实际数据跨度**（决定了「全部」区间分位与全历史回测的可用长度）：

| 标的 | 起 | 交易日 | 说明 |
|---|---|---|---|
| 标普500 | 1990-01 | 9331 | 东财 |
| 纳斯达克100 | 1996-06 | 7835 | 官网 + 东财拼接（本次升级，原为 2019-04） |
| 上证50 | 2004-01 | 5549 | |
| 黄金 | 2004-01 | 5559 | 上海金交所 AU9999 现货（元/克），可用黄金 ETF 518880 跟踪 |

## 四、快速开始

双击 **`启动.bat`**，会起一个本地 HTTP 服务并自动打开浏览器；关闭那个黑色窗口即停止服务。

### 启动方式

| 方式 | 会怎样 | 什么时候用 |
|---|---|---|
| 双击 `启动.bat` | 起服务 + 自动开浏览器 | **日常从这里开始** |
| 浏览器打开 `http://127.0.0.1:8766/` | 直接进面板 | 服务已在跑，只想打开页面 |
| 看 `网址.txt` | 纯文本，记录当前真实地址 | 端口顺延后到这里查准确网址 |

服务默认占用 **8766**；若该端口被别的程序占用会顺延到 8767、8768…，
`网址.txt` 会在每次启动时被改写成真实地址。

命令行等价：

```bash
python 服务端.py
```

**环境**：Python 3.9+（3.13 / 3.14 实测通过），只用标准库（`http.server` / `urllib` / `json` /
`concurrent.futures`），不需要 `pip install`。前端 ECharts 已离线内置于 `web/vendor/`，断网也能开页面看缓存数据。

`启动.bat` 会依次查找解释器：环境变量 `PYTHON` → 标准安装目录 → `PATH` 里的 `python`。
装了多个版本、想指定某一个时，先 `set PYTHON=D://Python//python.exe` 再双击即可。

## 五、界面与参数

主界面只留「一眼要用」的东西，所有解释性文字默认收起，点右上角 `?` 再展开：

- **顶栏**：数据更新时间、刷新、参数、说明（`?`）；
- **概览行**：加码/增额、常规、减额/缩量的只数 + 平均温度，一行四个数字，无边框无底色；
- **卡片**：温度条（只留渐变与指针，不再重复「冷/中性/热」文字）、倍率与档位标签、本期建议金额、PE 分位、距高点、距 MA200、**距 10 年趋势**、近 60 日走势；
- **详情**：K 线（含 **MA5 / MA10 / MA20 / MA60 / MA200** 五条均线、成交额、可缩放），K 线上方一行给出**该区间的涨幅、年化、区间最高/最低、起止日期与交易日数**（切 1月/3月/6月/1年/3年/5年/10年/全部 时同步重算）；定投回测曲线；因子明细表（每项读数、得分、权重）；
  - 均线图例可点击单条隐藏/显示；悬停十字光标时，浮层给出该日开高低收与五条均线的具体数值；
  - 均线配色避开涨红跌绿（MA5 橙 / MA10 金 / MA20 紫 / MA60 青 / MA200 蓝），避免与红绿 K 线混淆；
  - **怎么读**：MA5、MA10 看短线强弱（价格在 MA5 上方、且 MA5 > MA10 为短线走强）；MA20 是月线，中期趋势的分界；
    MA60 是季线，代表季度平均成本；MA200 是年线，长期牛熊分界。五线由上到下依次排列且发散＝趋势顺畅，
    缠绕在一起＝震荡市，此时信号的加减额更该按纪律执行而不是按感觉；
  - 均线在全历史上滚动计算后再切到所选区间，所以 1 个月视图里的 MA200 也是真实值，不是空线；
  - 区间含「纳斯达克官网历史」（无成交量）时自动隐藏成交额副图并提示，不把缺失画成 0；
- **参数**（右上角「参数」，自动存 localStorage）：
  - **评分模型**：v2 趋势校准（默认）/ v1 旧版（对照用，见 2.1）
  - 分位窗口：3 年 / 5 年 / 10 年 / 全历史 —— **仅 v1 生效**；v2 的分位一律用该标的全部可得历史，
    因为分位要稳定就不能换窗口（这也是 v1 的一个隐藏问题：窗口一变，结论就变）
  - 估值权重：0–60% —— 仅 v1 生效；v2 的权重由回测校准，固定 18%
  - 每期基准金额
  - 定投频率：每周 / 每两周 / 每月
  - 自动刷新：关闭 / 60 秒 / 5 分钟

## 六、口径与限制（请先读这一段）

1. **分位不是概率**。温度 30 只说明「按这五个维度，当前比该标的自身 70% 的历史时点更便宜」，
   不预测未来，也不跨标的比较——恒生的 30 和纳指的 30 含义不同。
2. **估值分位窗口不同源**。蛋卷基金的 PE/PB 分位与本地算的价格分位窗口并不一致（前者窗口未公开），所以二者合成时只能算近似。
3. **A500 的历史是回溯数据**。中证A500 2024 年 9 月才发布，2024 年之前是编制方回溯，分位仅供参考。
4. **部分指数历史天生短**。科创50 只有 6.9 年（2020-07 才发布），创业板50、恒生科技各约 12 年，
   都是指数发布/基日所限，**外部没有任何合法长历史可补**。v2 的分位基于全部可得历史，
   所以这三只标的的分位样本天然偏少（尤其「距 10 年趋势」实际只覆盖了 5–7 年），
   结论置信度要相应打折。纳指100 已从 7 年补到 30 年（1996 起）。
5. **跨境标的**另有汇率、QDII 溢价、额度限制，页面上的价格分位不含这些摩擦成本。
6. **均线口径**。五条线都是收盘价的简单移动平均（SMA），指数为价格指数、不含分红，所以与「全收益指数」的均线会有细微差异。
   均线**在全历史上滚动计算**后只做区间截取，不做二次重算，因此短区间（1 个月）里的 MA200 仍是真实值。
   均线是滞后指标，本平台的加码/减额判断**不看均线**，均线只用于人工确认趋势，别把「站上年线」当买入信号。
7. **信号是纪律工具，不是择时圣杯**。同预算口径（月投 1000、每期预算 2000、闲置现金入账）：

| 标的 | 区间 | v2 同预算财富 | 等额 | 相对 |
|---|---|---|---|---|
| 沪深300 | 2006-01 ~ 2026-10 | 1.19× | 1.16× | +2.8% |
| 中证500 | 2006-01 ~ 2026-10 | 1.34× | 1.29× | +3.6% |
| 中证1000 | 2006-01 ~ 2026-10 | 1.32× | 1.26× | +4.2% |
| 创业板50 | 2015-06 ~ 2026-10 | 1.19× | 1.13× | +4.8% |
| 科创50 | 2021-01 ~ 2026-11 | 1.12× | 1.08× | +3.3% |
| 中证A500 | 2006-01 ~ 2026-10 | 1.28× | 1.23× | +3.5% |
| 上证50 | 2005-01 ~ 2026-11 | 1.20× | 1.18× | +1.5% |
| 标普500 | 1990-12 ~ 2026-10 | 4.22× | 3.85× | +9.6% |
| 纳斯达克100 | 1997-05 ~ 2026-11 | **6.81×** | 5.97× | **+14.1%** |
| 恒生科技 | 2016-01 ~ 2026-11 | 0.96× | 0.95× | +0.5% |
| 黄金 | 2005-02 ~ 2026-11 | 2.39× | 2.14× | **+11.7%** |

   **11 只全部优于等额定投，平均 +5.4%**。恒生科技只领先 0.5%，本质是该指数自 2021 年起
   一路下行，任何「逢低加码」都是在摊薄一个持续下跌的资产 —— 这类标的的信号该降权使用，不能硬扛。

   与 v1 相比（同一口径）：v2 在标普500 上财富高 **46.3%**、黄金高 28.5%、纳指100 高 9.2%，
   中证500 / 中证1000 / 中证A500 上优 1.7–7.9%；但在创业板50（−5.3%）、科创50（−4.6%）、
   上证50（−5.1%）、恒生科技（−2.3%）上逊于 v1。**没有哪一版在所有标的上都更好，这是取舍。**

   代价是最大浮亏更深（低位加倍所致，沪深300 −24.8% vs 等额 −15.7%）。这些结果原样展示，不做粉饰。

   黄金值得单独说一句：v1 在黄金上是 **−13.1%**（落后等额），v2 是 **+11.7%**。原因是金价长期上行，
   「价格在窗口内的分位」几乎永远偏高 → v1 一路判贵、一路少投，把一个本该重仓的品种买成了轻仓。
   这正是 2.1 所述偏差最纯粹的暴露，也是加黄金反而验证了 v2 的那处修正。

### 附·黄金与股票指数的口径差异

黄金没有盈利，没有 PE/PB，也不分红。所以：

- **估值因子自动剔除**。其余四项按原比例归一（28/18/18/18 → 34%/22%/22%/22%），不硬塞一个假估值。
- **「贵」更依赖距长期趋势的偏离**（权重从 18% 升到 22%）。金价的长期中枢由货币信用扩张决定，
  偏离这条 10 年趋势线多少，比「绝对价位」有意义。
- **卡片的「PE 分位」一栏换成「年内位置」**（当前价在近 250 日高低区间中的位置），因为黄金没有估值可看。
- **它不能和股指一起横向比较温度**。金价和 A 股、美股的相关性低，同一天两边都给 1.5× 是正常的分散，
  不是重复下注。
- 标的是**上海金交所 AU9999 现货（元/克）**，反映国内人民币金价，与 COMEX 美元金价会有溢价/汇率差异；
  实际可买标的是黄金 ETF（如 518880），跟踪误差、管理费不体现在这里。

```
宽基监控/
├─ 服务端.py          # 抓数据 + 算指标 + 跑回测 + 静态托管（单文件，标准库）
```

两个只在本机存在、不进版本库的东西：

- `网址.txt` —— 每次启动由服务端写入当前真实地址，故在 `.gitignore` 中；
- 开发过程记录（工作日志、教学笔记）留在本地，通过 `.git/info/exclude` 排除，
  避免把过程性内容混进公开仓库。
